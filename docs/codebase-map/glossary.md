# Glossary

## Broadcast

**Meaning:** Explicit HTTP-triggered push delivery to a selected audience.
**Evidence:** `src/handlers/broadcast.ts`.

## Reminder plan

**Meaning:** Scheduler-derived notification work for active schedules.
**Evidence:** `src/services/scheduler.ts`.

## Webhook

**Meaning:** Incoming event route that maps supported database records to notifications.
**Evidence:** `src/handlers/webhook.ts`.
